 **BULB GLOW USING AND LOGIC GATE**

**1\. Aim**  
To design a simple digital logic circuit using an AND gate to control the glowing of a bulb/LED.

**2.Problem Statement**  
In some control systems, the output should be activated only when both required conditions are satisfied.

**3\. Proposed Solution**  
An AND gate is used so that the bulb/LED glows only when both input conditions are HIGH (1).

**4\. Components Required**  
AND Gate IC (7408)  
LED/Bulb  
Resistor  
Breadboard  
Jumper wires  
Battery/Power supply  
Switches

**5\. Circuit Working**  
The AND gate has two inputs, A and B, and one output. The bulb/LED glows only when both A and B are HIGH.  
Logic:  
A \= 1, B \= 1 → Output \= 1 → Bulb ON  
Any other input combination → Output \= 0 → Bulb OFF  
6\. Procedure

* Place the AND gate IC on the breadboard.  
* Connect the IC to the required power supply.  
* Connect two switches to the input terminals A and B.  
* Connect the output to the LED/bulb through a resistor.  
* Apply different input combinations.  
* Observe the LED/bulb according to the AND gate truth table.


**7\. Applications**

* Security systems  
* Industrial control systems  
* Safety circuits  
* Automatic control systems  
* Digital electronic circuits


**8\. Advantages**

* Simple circuit  
* Easy to understand  
* Low cost  
* Reliable operation  
* Demonstrates basic digital logic


**9\. Result**  
The bulb/LED glows only when both inputs of the AND gate are HIGH, verifying the AND gate operation.

**10\. Conclusion**  
The project successfully demonstrates the working of an AND logic gate, where the output becomes HIGH only when both inputs are HIGH.

**11\. Project Demonstration**  
The project demonstrates how two input conditions can be used to control a bulb/LED using an AND logic gate.
